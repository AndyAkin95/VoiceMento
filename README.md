# VoiceMento MVP

A front-end MVP for a digital audio/video guestbook business for weddings and events.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy free on Vercel

1. Upload this folder to a GitHub repository.
2. Import the repo into Vercel.
3. Framework preset: Next.js.
4. Deploy.

## Included in this MVP

- Event dashboard
- Custom event name/date/prompt/accent color
- Booth/kiosk mode
- Audio vs video message flow demo
- Local demo message history
- Guest QR/event code concept
- Mobile/tablet responsive interface

## Production next step

Connect Supabase for authentication, event/client records, cloud message storage, uploads, QR links, galleries and exports. Browser microphone/camera recording can then be wired to Supabase Storage.
